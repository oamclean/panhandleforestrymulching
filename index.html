How to add a new version
  1. Create a new folder at the repo root, e.g. v2/.
  2. Build out the variant inside it — pages, assets, and a self-contained css/ and js/.
  3. Add a new <article class="card"> to this page pointing at v2/index.html.
  4. When a variant ships to production, point the site's deploy at v{n}/ as the document root.
